## Design references

The work takes inspiration from the supplied reference websites, while using distinct naming, content, visual treatments and page composition rather than reusing a single template.

## Notes

- Each project is a standalone responsive page with its own embedded styles and JavaScript.
- The forms, quote requests, reservations and basket interactions are demonstration interfaces. Connect the relevant business email, CRM, booking provider or commerce backend before using them in production.
- Demo prices, sample reviews, locations and specifications are illustrative and must be replaced with verified business information.
- Images supplied in the project folders are retained where used. Selected supplementary photographs are loaded from Unsplash and remain subject to the Unsplash License.
- GitHub Pages deployment is configured through the deployment workflow and runs on pushes to the main branch.
